# Collector contract v1

Mechanism: Python standard-library ctypes calls Windows IP Helper GetExtendedTcpTable(AF_INET,TCP_TABLE_OWNER_PID_ALL), GetProcessTimes, GetProcessMemoryInfo and GetProcessIoCounters. No ETW/provider session, packet capture, network payload or kernel allocator attribution. Hypothesis: persistent loopback IPv4 occupancy and task-owned process lifetimes can be sampled cheaply enough to contextualize first transport failure. IPv6 and instantaneous peaks between samples are UNAVAILABLE, not zero. Rows returned by Windows are point snapshots, not events. PID0/TIME_WAIT owner and exited/reused PID attribution remain UNKNOWN without matching creationtime.

Every artifact is in a new owner-token directory; start exclusive owner.json+samples.ndjson, no overwrite. Stop writes stop.request only when token matches; repeated stop is safe. Collector exits on stop,120s duration,8MiB sample file limit or parent exit. Maximum raw native TCP buffer1MiB,8192rows; at most512 loopback rows serialized/sample; droppedRows reported. No circular overwrite; full condition finalizes reasonSIZE_LIMIT. At most100ms frequency; performance monotonic and UTC measured before/after every snapshot. GetExtendedTcpTable size-race bounded3 attempts, with real error codes. Unsupported API/error produces UNAVAILABLE; no synthetic zero. No external endpoints serialized, no names/commandlines/environment/cookies/token/payload. Only127/8 local endpoints and loopback/listen remotes stored. Nonloopback endpoints omitted before serialization.

Schema v1: header(sessionToken,ownerPid,birthFiletime,utc,monotonicNs,platform,sourceSha256); samples(seq,utc,monotonicNs,elapsedMs,sampleCostMs,tcp.support/status,loopbackCount,uniqueLocalPorts,stateCounts,rows[state,local,remote,pid,identity],collector[cpu100ns,workingSetBytes,ioCounters],droppedRows); summary(reason,first/last timestamps,samples,bytes,droppedRows,overruns,errors,summaryPreparationMs). Filetime identity is exact Windows100ns creation stamp, noPID-only attribution. Process query failure carriesWin32code and UNKNOWN identity; it is never cached across samples. APIs operate query-only handles closed in finally. Workload markers use same OS monotonic clock+UTC and exact endpoints; clock offset interval, not assumed identicalremote clock. Raw parser validates sequence/schema/bounds/endstate and correlation using PID+birth plus endpoint/time overlap. Reports quantiles and missingness.

Stop timeout2s parent wait then ownedchild kill fallback, recorded FAILURE; normalstop must exit0 and flush summary. KeyboardInterrupt/SIGTERM handled wherePython supports; qualification tests stopfile and bounded cancellation, not forcedVMtermination. Parent validates exactchildhandle/token before kill; no global process/session cleanup. Artifacts retained7days onGitHub, local evidence unchanged.
