## Evidence and acceptance limits

Persisted JSON contains case statuses, selected event timestamps, callback/conflict details, synthetic identities, the valid201 control, the candidate effect ID and selected response statuses. The raw TAP and exact reviewed test source establish the remaining assertions. Full HTTP bodies and full before/after database snapshots are not persisted for every matrix case; all-document equality is an executed in-memory assertion. Some cases persist only PASS rather than every individual asserted status. These distinctions must survive publication.

The event barriers use test-only adapter interception or isolated-candidate hooks; they do not remove either actual guard's fences. Their timeouts bound the harness and are not product latency targets. The candidate's trusted withdrawal is not a public HTTP permission surface or an official production invalidator. Retained tenant permit capacity, routine history bounds, and selected/requested dependencies remain as documented in the experiment contract; this matrix is not exhaustive certification of every coherent corruption, maximum-history combination or authority-writer interleaving.

F5-A has produced a reproducible rejection, not an accepted authorization optimization. Production guards remain intact. No performance benchmark, full browser campaign, physical throughput, stock/financial integration or general manufactured graph acceptance follows from30 passing tests. Any replacement candidate would need an explicit revised design, the full authority-writer contract and new proof before adoption.
