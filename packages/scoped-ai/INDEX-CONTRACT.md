# Scoped index contract — PLAT-044

Implementation milestone; independent acceptance remains TPR-150/152. No real model results have been produced.

`status(scope, {plantId, resourceId})` requires `ai.index` plus current authoritative source access in a transaction. It returns index revision (zero before first publication), current source/ACL revisions, configured/indexed model, and `NOT_INDEXED`, `REVOKED`, `MODEL_CHANGED`, `SOURCE_CHANGED` or `CURRENT`. It does not contact either provider or expose vector IDs/content. `CURRENT` describes the authorized snapshot and does not prove vector service availability. All other states offer `REBUILD` with the returned expected revision; source revocation denies status rather than disclosing retained metadata. HTTP: `GET /api/ai/documents/:id/index`; explicit index deactivation: `POST /api/ai/documents/:id/index/revoke` with `{key, expectedRevision}`. Both use selected-plant scope and no-store responses. Source revocation is distinct and remains enforced at retrieval regardless of index state.

`createScopedIndex` takes the existing foundation, Mongo client/db, a trusted `source.readAuthorized`, an explicitly authorized embedding adapter, and a Qdrant vector adapter. Call `initialize` only from the integrator's authorized lifecycle. No indexes, collections or services are initialized on import. Foundation roles exported as `aiRoles` must be registered by CTO; an AI role does not grant source access.

The source adapter receives `{scope, grant, resourceId, session}` and must validate tenant, plant, legal entity and current per-user ACL; perform a real write fence on its authoritative resource/ACL in that transaction; deny missing/revoked resources; return resource UUID, positive revision and ACL revision, title, and up to 100 plain-text chunks (4,000 characters each, 100,000 total). It must not interpret source text as instructions. This port is mandatory and has no permissive fallback. Concrete manual/approved-PO ingestion and HTTP/UI composition are described in INGESTION-CONTRACT.md.

Rebuild reads an authorized snapshot, computes embeddings outside transactions, uploads reference-only points and atomically publishes an active generation after rechecking the same source hash. Rebuild uses expected index revision and command key. Unknown upserts or failed publication leave inert orphan points. Reconcile the same key; never claim an unconfirmed generation is active. There is no automatic retry of vector writes and no live-send capability. An idempotent replay can create inert points before reconciling the existing command receipt; it cannot reactivate revoked authority. Prior committed generations are tracked in retiredPoints with a 1000-ID bound. `cleanup(scope,{plantId,resourceId,key,expectedRevision})` / POST `/api/ai/documents/:id/index/cleanup` deletes at most 100 exact retired UUIDs or revoked generation IDs, preserving active points. Provider completion is required before CAS/audit/result/outbox bookkeeping; lost acknowledgements safely repeat exact-ID deletion. Same-key committed cleanup replays its receipt. Unknown untracked pre-publication orphans remain inert; automatic wildcard/collection erasure is unsupported. Status/UI show retired count and cleanup action. Lifecycle/configuration/recovery boundaries are in ops/ai/OPERATIONS.md.

Retrieval filters tenant/plant/model in Qdrant, caps candidates at 40 and citations at 10, then reauthorizes in a transaction. Every citation requires an active matching generation/point ID, current source revision/ACL/hash and write fences on source and index. Denied source access and stale candidates are excluded. Unexpected source errors fail closed. No cross-resource text is accepted from vector payloads. Citations identify document evidence, model, source/index/ACL revision and untrusted content. Top-k coverage is explicit; empty results do not assert the tenant has no documents. No answer synthesis or prompt-injection execution occurs in this layer.

Provider calls have 10-second abort and response deadlines; a port that ignores abort may continue background computation but cannot publish index authority through this API after timeout. Host adapters must honor cancellation and must use only an authorized provider/model/privacy boundary. No default embedding provider, model enrollment, fake vectors or fallback model exists. Query text is sent only to that configured embedding adapter; no personal conversation history is collected.

Qdrant REST contract verified using current primary reference via find-docs: [query points](https://api.qdrant.tech/api-reference/search/query-points), [upsert points](https://api.qdrant.tech/api-reference/points/upsert-points). Config fixes base host, collection and dimensions; TLS required except loopback, credentials only in header, redirects refused, response capped at 1 MiB, reference-only payload allowlist. Collection provisioning and payload indexes remain integrator lifecycle work. Model/dimension changes require a compatible collection and rebuild; stale old-model points are rejected. No production connection or Qdrant runtime acceptance has occurred.
