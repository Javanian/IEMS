# Scoped assistants, PLAT-028

Implementation uses explicit typed lookups. No LLM generation, conversation storage, automatic action or send capability exists. A model synthesis boundary remains external; document quotes never stand in for current order state. Authorized model access is not implied by an AI role. Independent acceptance remains final integrated QA.

`createScopedAssistants({foundation, customerService, rag, clock?, timeoutMs?, maxAgeMs?})` exports `ask(scope,input)`. Requires `ai.retrieve` at entry and after awaiting the source. Existing CS methods enforce `cs.ticket.read` and their own binding, customer and source transaction fences. RAG enforces authoritative document ACL. No direct collection fallback exists. Timeout is capped at 10 seconds; freshness at 60 seconds (default 30). A timeout returns abstention even if a port ignores cancellation; this layer never retries or publishes side effects. Underlying CS/RAG reads may complete their own read-fence transactions after timeout.

Input kinds, in addition to selected plant UUID:

- `ORDER`: binding UUID and order number. Calls only `customerService.getOrderStatusForBinding`. Requires owned source, liveLookup, positive source version, matching order number and fresh observation time. Fixture, stale and future snapshots abstain. Output projects only public order fields, source ID/version and confirmed milestones/dates.
- `SERVICE_METRICS`: ISO UTC `from`/`to`, increasing, at most 31 days, no future end. Calls only existing `getMetrics`; preserves definitions, timing nulls and synthetic/seeded/unknown provenance. Incomplete scans abstain and expose no sampled counts. No invented percentiles or delivery inference.
- `DOCUMENTS`: nonempty query up to 2,000 characters, optional limit 1..10. Calls authorized RAG; output is `DOCUMENT_EVIDENCE`, retains revision citations and marks all text untrusted. Empty authorized results abstain, with bounded-top-k meaning retained. No tool execution, HTML interpretation, source instructions or live-order assertion.

Source unavailable/timeout yields `ABSTAIN/SOURCE_UNAVAILABLE`. Authentication, authorization, missing/revoked source and unexpected integrity/storage errors propagate. All inputs reject unknown fields including history and alternate scope. Responses use `SCOPED_ASSISTANT_V1`, `generated:false`, `historyStored:false`; freshness is a source snapshot observation, not a guarantee of future state.
