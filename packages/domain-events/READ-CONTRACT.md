# Domain events to reporting

Source authority remains MongoDB domain state. Use foundation `commands.execute` for domain/result/audit/outbox atomicity; do not call a broker inside the domain transaction. This package consumes that durable outbox. KafkaJS-compatible injected producer must use idempotent production configuration, TLS/auth and `acks=-1`. A lost publish marker can duplicate an envelope. Partition by tenant/plant/aggregate. Invalid schema stops publication without deleting source evidence.

Relay requires an explicit eventTypes allowlist and a single active publisher owner. Its kafkaPublishedAt marker is separate from publishedAt used by other transports (including platform Rabbit jobs); neither transport suppresses the other's delivery. Rows are sorted by aggregate revision, including same-millisecond commands. Integration must provision the scoped outbox routing/publication index before workload deployment, under its migration gate; no index is applied here. Route only mapped snapshot event types to reporting marts; retain unrelated domain events in their own raw stream without inventing snapshot fields.

Envelope v1: eventId/schemaVersion/tenantId/plantId/aggregateId/aggregateVersion/type/occurredAt/payload. IDs are UUIDs; timestamps UTC; decimal values strings with explicit currency/UOM. Payloads are full resource snapshots for analytics, with `deleted: true` tombstones, `resourceType`, and resource-specific fields. Unknown schema/type must quarantine, never infer domain meaning. Multiple events for one aggregate revision need distinct stream aggregates; the sequential consumer rejects ambiguous same-version events. Domain owners must explicitly map their events before enabling consumers.

Consumer authorization callback is mandatory. Mongo projection receipt, version head and effect share one transaction/session. Apply callbacks perform only Mongo writes using that session. Kafka offsets advance after commit. Revoke/deactivate producer scopes through authorization callback. Version gaps block and require source replay; no silent skip. Event ID reuse with changed content fails. Keep receipts for the replay horizon; deleting receipts requires an approved full rebuild.

Downstream raw files are immutable versioned envelopes plus receipt/availability timestamps, checksums and cursor ranges. Publication requires reconciled manifests and successful quality gates. Reporting is read only, never a writable business ledger. No SAP posting, source mutation, production migrations or cloud acceptance are included.

Integration owner supplies Kafka client lifecycle, source type mapping, service authorization and foundation runtime wiring. No root manifest/router change is made here. Minimum syntax is separate from final independent broker/restart/reconciliation QA.
# Reporting snapshot v2 helper (TPR-153 amendment)

`snapshot-source.mjs` exports initializeReportingSnapshots, appendReportingSnapshot and relayReportingSnapshots. Integration must initialize its unique indexes before enabling producers, and run exactly one reporting publisher. Caller must authorize the source resource inside its active Mongo transaction and pass the fresh foundation grant. Helper never starts/commits a transaction or sends a broker message inside it. Duplicate source keys reauthorize at caller, return the persisted event, and reject changed semantic content. Abort the entire transaction on any helper error. CAS/index contention retries the entire authorized source transaction with the same immutable evidence.

Topic `iems.reporting.snapshots.v2`, collection reportingSnapshotOutbox, marker reportingKafkaPublishedAt; original outbox and Rabbit markers remain independent. Replay retains reportingSnapshotSources and immutable outbox. Mapping version 1 only; another mapping requires isolated projection/topic epoch. Source key: scoped collection/id/version/target eventKey/type/mapping version. eventKey MUST be the stable grouping identity (order UUID, shipment UUID, or payment UUID + order UUID), identical in bootstrap and live writes. Source hash MUST cover the exact immutable source fields, excluding observation metadata. Source event IDs identify original evidence, never snapshot sequence. Full snapshots include baseline, deleted, legalEntityId and resource fields; tombstones retain last complete values. Physical disappearance does not authorize a tombstone.

NOT_YET_WIRED: commercial order append belongs to TPR-140; payment/shipment/correction emitters belong to fulfillment and respective vertical owners. CTO TPR-149 owns lifecycle/index registration and single publisher startup. This helper commit is a usable prerequisite, not proof of live producer adoption. Runtime/restart/rollback/replay QA remains NOT_RUN until TPR-150/152.
